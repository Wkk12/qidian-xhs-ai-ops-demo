## R19 内容工坊重构

1. **顶部生成入口去重**：现有「生成方案/一周内容批量创作」+「AI GENERATION/生成内容·7天窗口」+ 顶栏全局「生成 7 天内容」按钮互相冲突 → **收敛为一个统一生成入口**。
2. **生成逻辑**：
   - 第一次 / 没有内容时 → 生成 **7 天**（7 篇，沿七天叙事）
   - 已有内容时 → 生成 **1 篇**
   - 生成后可**选择放到哪天发送**（直接排期）
3. **「一起生图」开关**：生成文章时可选是否**同时根据内容自动生成配图**（不用手动输入提示词）。
4. **生图板块移到右侧**：可**单独生图**（与文章生成独立）。
5. **行业热榜移位置**：放到「待发送内容」列表**下面**。
6. **待发送内容池**（= 生成但没发的内容）新规则：
   - 未安排进排期的文章，**从生成时间起计时 7 天 → 自动删除**
   - 每篇带**收藏（书签）标志：收藏后永久保留**，不参与自动删除
   - 验收：造一条 7 天前的模拟数据验证删除；收藏的必须活着。

## R20 排期发布改版

1. **「自动发布前调度」改造**：
   - 保留「发布前 15 分钟自动预检」（必要项，不动）
   - 开关改成「**自动发送**」：
     - **关闭** = 到点需**手动确认**，确认后自动发送
     - **打开** = 无需询问，系统直接发送
2. **发布保护加开关**（是否保护）：
   - 开（默认）= 五项预检全过才发送
   - 关 = 跳过预检直接进入发送流程
3. **建议发布时间**：
   - 默认**按 AI 运营策略走**（策略里定义时间表），无需手动
   - 后面按钮改为「**手动调整**」（想自己定时才点它）
   - 新增「**实际发送时间**」（真实发出时间，来自发布任务记录）
4. **发布队列 → 周视图**：
   - 上面一排：**周一/周二/…/周日**，点击日期查看当天要发送的文章
   - 默认进入页面定位到**今天**
   - 文章默认是**横条**；点击后**向下展开**：
     - 展开分两部分：**左侧 = 文章内容**，**右侧 = 手机屏幕**（小红书里长什么样的真机预览）
     - 下面按钮：**预检 / 编辑 / 保存**
     - **预检结果**显示在**手机下面单独的框**里
