# 绮点 AI 小红书运营平台 · 交付说明（Mac 版）

> 适用：**Intel 芯片的 Mac**（Apple 芯片也可用，见文末附注）
> 全部数据都存在**这台电脑本机**，不上传任何第三方服务器。

---

## 第 1 步：装 Node.js（只需一次）

1. 打开浏览器访问 **https://nodejs.org/zh-cn**
2. 点绿色的 **LTS** 按钮下载（约 60 MB）
3. 双击下载好的 `.pkg` 文件 → 一路点「继续」→ 装完

> 已经装过可以跳过。不确定的话直接做第 2 步，程序会自己提示。

---

## 第 2 步：把整个文件夹放到桌面

把 `绮点小红书运营系统` 这个文件夹**拖动到桌面**。

> 放在桌面是为了路径短、不出权限问题。放别的地方也行，但**路径里不要有中文空格以外的特殊符号**。

---

## 第 3 步：给启动文件开权限（只需一次）

> ✅ 交付包的 zip 里**已经带好了执行权限**，正常情况下第 4 步直接双击即可。
> 如果双击提示「因为它是一个文稿，无法执行」或权限被解压工具清掉了，**再按下面做一次**：

Mac 默认不让双击运行下载来的脚本，需要开一次权限：

1. 打开 **「启动台」→「其他」→「终端」**
2. 复制下面这行，粘贴进终端，**按回车**：

```bash
chmod +x ~/Desktop/绮点小红书运营系统/mac/启动.command
```

> 如果文件夹没放桌面，把 `~/Desktop/绮点小红书运营系统` 换成你的实际路径。
> 小技巧：在终端里输入 `chmod +x ` 之后，**把启动文件直接拖进终端窗口**，路径会自动补全。

---

## 第 4 步：双击启动

打开文件夹 → `mac` → **双击 `启动.command`**

- 首次运行会**自动安装依赖**（约 1–3 分钟，只有第一次）
- 之后每次启动约 5 秒
- 启动完成后**浏览器会自动打开操作界面**

> 如果双击后提示「无法打开，因为来自身份不明的开发者」：
> **右键点它 → 选「打开」→ 再点「打开」**，之后就能正常双击了。

**启动成功的样子**：终端里出现

```
✅ 依赖已就绪
✅ 小红书连接服务已启动（端口 18060）
✅ 主服务已就绪
 已启动完成！界面在浏览器里打开了
```

---

## 第 5 步：扫码登录小红书（只需一次）

1. 界面打开后，进入 **「系统设置」**
2. 看到「小红书连接服务」是**正常**就说明通了
3. 若提示未登录 → 点**扫码登录**，用小红书 App 扫码
4. 登录状态会保存在本机，**之后不用反复扫码**

> ⚠️ 登录态大约能维持数周。失效时重新扫一次即可。

## 数据与备份

所有数据都在这两个位置（都在本机）：

| 内容 | 位置 |
|---|---|
| 数据库（笔记/内容/评论/填报） | `绮点小红书运营系统/server/data/xhs-ops.db` |
| 图片素材 | `绮点小红书运营系统/server/data/uploads/` |

**备份方法**：把整个 `server/data` 文件夹复制一份到移动硬盘或云盘即可。
**换电脑**：把 `server/data` 拷过去覆盖，数据就完整迁移了。

## 常见问题

**Q：双击没反应？**
先在终端里手动跑一遍看报错：
```bash
~/Desktop/绮点小红书运营系统/mac/启动.command
```

**Q：提示 Node.js 版本太低？**
去 https://nodejs.org/zh-cn 装最新的 LTS 版本。

**Q：端口被占用 / 界面打不开？**
终端里执行：
```bash
lsof -i :8787 | grep LISTEN
kill -9 <上面查到的进程号>
```
然后重新双击启动。

**Q：发布失败？**
多半是小红书登录态失效了 → 系统设置里重新扫码。
也可能是小红书临时风控，等 10–30 分钟再试。

**Q：评论自动回复没动静？**
1. 确认「评论自动回复」里的**观察期**已结束（首次开启后 3 天）
2. 确认**知识库里有内容**（未命中知识库的评论不会自动回复，会进人工待办）
3. 确认该用户不在**人工介入名单**里

## 附注：Apple 芯片（M1/M2/M3/M4）的 Mac

包内同时提供了两个版本的连接程序：

- `mcp/xiaohongshu-mcp-darwin-amd64` → Intel Mac 用
- `mcp/xiaohongshu-mcp-darwin-arm64` → Apple 芯片用

启动脚本会**自动挑合适的那个**，不需要手动选。

## 安全说明

- 交付包内**不包含任何 API 密钥**
- 所有密钥如需使用，存于本机 `server/.env`（该文件不在包内，需自行配置）
- 小红书账号登录态只存本机，不上传
- 程序只访问本机 `127.0.0.1`，外部无法主动连入
