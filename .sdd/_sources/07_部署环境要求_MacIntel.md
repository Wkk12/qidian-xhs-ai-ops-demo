# 绮点 AI 小红书运营平台 · 部署环境要求（macOS Intel 版）

> 客户机器：**Mac（Intel CPU / x64）** —— 这一点会改变交付方案，下面说清需要改什么。

---

## 一、核心结论

**当前工程是 Windows 版，交付 Intel Mac 需要 4 处适配**，其中**只有 1 处是硬骨头**：

| 组件 | 当前（Windows） | Mac Intel 需要的 | 难度 |
|---|---|---|---|
| 本地服务（Node） | `node.exe` | Node.js **darwin-x64** | ✅ 官方有现成版 |
| 数据库 | `node:sqlite`（Node 内置） | **同样内置**，零改动 | ✅ 无 |
| 前端页面 | 静态产物由后端托管 | **同样**，零改动 | ✅ 无 |
| **发布通道** | `xiaohongshu-mcp-windows-amd64.exe` | ⚠️ 官方 **只发布了 darwin-arm64**（Apple 芯片），**Intel Mac 必须自己编译 darwin-amd64** | ⚠️ **需交叉编译 + 真机验证** |
| 浏览器内核 | 自动下载 Chromium | Mac 版自动下载 | ✅ 无 |
| 启动方式 | `启动.bat` | `.command` 脚本或 `.app` | ✅ 简单 |

## 四、Intel Mac 适配清单（开发侧要做的事）

### 1. 发布通道：交叉编译 darwin-amd64 ⚠️ 唯一的硬骨头
- 官方 release 资产只有：`darwin-arm64` / `linux-amd64` / `windows-amd64`
- **Intel Mac 不在其中** → 需要自己编：
  ```bash
  GOOS=darwin GOARCH=amd64 go build -o bin/xiaohongshu-mcp-darwin-amd64 .
  ```
  （**在任意装了 Go 的机器上都能编，不需要 Mac 本机**——我们现在这台就已经编过一次 Windows 版了）
- 编完**必须在真机跑一次**：登录 → 搜索 → 发布，确认可用

### 2. 启动方式改造
```bash
# 启动.command（双击运行）
#!/bin/bash
cd "$(dirname "$0")"
node app/server/src/index.js &
sleep 3
open http://127.0.0.1:8787
```
- 记得 `chmod +x 启动.command`

### 3. macOS 安全机制（Gatekeeper）
未签名的程序首次打开会提示"无法验证开发者"。两种解法：
| 方案 | 成本 | 体验 |
|---|---|---|
| **a. 引导客户右键→打开→允许** | 免费 | 一次性操作，可接受 |
| **b. Apple 开发者签名 + 公证** | **$99/年** | 双击即用，无提示 |

> **建议先用 a**，客户能接受就省下年费。

### 4. 开机自启（Mac 用 launchd，比 Windows 更规范）
```
~/Library/LaunchAgents/com.qidian.xhs.plist
```

## 六、客户首次使用要做的 6 件事（≤ 10 分钟）

1. 双击 **「启动.command」**
2. 浏览器自动打开 → 进「系统设置」
3. **扫码登录小红书**（用客户自己的账号）
4. 填 **DeepSeek API Key**（内容生成用）
5. 填 **生图渠道 Key**（配图用）
6. 点「从我的小红书导入」把历史笔记收进文案库 + 设置「人设卡」
