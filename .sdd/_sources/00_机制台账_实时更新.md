## 一、项目一句话

给**化妆培训/美业客户**做的小红书 AI 运营平台：**本地部署、不依赖任何 AI 助手**，能做内容生成、配图、自动发布、数据分析、评论区回复。

**客户机器**：Mac（Intel CPU）—— 交付前需做 Mac 适配（详见 `07_部署环境要求_MacIntel.md`）

## 五、交接说明书（给接手的人看）

### 5.1 这是什么
一个跑在**本地电脑**上的小红书运营工具。**不需要联网 AI 账号、不需要装 Python/Java**，双击启动脚本 → 浏览器打开 `http://127.0.0.1:8787` 就能用。

### 5.2 现在能干的事（已验证的）
1. 看**真实账号数据**（粉丝/关注/获赞 + 浏览量/涨粉/曝光 30 天趋势）
2. **上传素材**（图库管理，能删）
3. **文案库**：一键导入自己已发的小红书笔记（现有 46 篇）
4. **选题参考**：搜小红书真实爆款（标题/作者/点赞/封面）
5. **系统设置**：看登录态、MCP 连接、密钥配置状态

### 5.3 还不能干的事（待开发）
- ❌ 生成文章（内容引擎未做）
- ❌ AI 生图
- ❌ 自动发布
- ❌ 评论区自动回复
- ❌ 对标账号分析
- ❌ 每日复盘报告

### 5.4 出了问题先看哪里
| 现象 | 检查 |
|---|---|
| 页面打不开 | 后端是否在跑：`netstat -ano \| grep 8787` |
| 数据不显示 | MCP 是否在跑：`curl localhost:18060/health` |
| 登录失效 | 重新扫码：`/api/mcp/qrcode` |
| 平台数据拿不到 | cookie 是否过期（`xiaohongshu-mcp-go/cookies.json`）|

### 5.5 怎么继续开发
1. 看本台账的「开发优先级」
2. 每完成一项 → **更新本台账**（状态改 ✅，补验证证据）
3. 代码在 `xhs-ops-platform`：`server/`（后端）、`web/`（前端）
4. 改前端后必须 `npm run build`，改后端重启服务

| # | 坑 | 解法 |
|---|---|---|
| 1 | **MCP 连续快速请求会返回"服务器内部错误"**（限流） | 抓取间隔 ≥3.5 秒；连续任务之间也要间隔几十秒 |
| 2 | `ModuleViews` 由 `v-else` 挂载 → watch 不捕获初始值 → 首次进入模块不加载数据 | `onMounted(() => onViewChange(props.activeView))` 兜底 |
| 3 | 改完前端浏览器缓存旧 JS | `npm run build` 后用 `?v=N` 强制刷新 |
| 4 | 搜索返回结构是 `r.data.feeds`（不是 `data.data.items`） | 见 `/api/mcp/search` 的解析 |
| 5 | Windows curl 发中文 body 会乱码 | 用 Python requests |
| 6 | 后台进程挂 Hermes 进程树会被连带杀 | 用 `Start-Process` 独立启动 |
| 7 | 创作者中心用**泛域 cookie**，无需额外签名 | 复用 `xiaohongshu-mcp-go/cookies.json` |
| 8 | **查重：导入的历史笔记只有标题没正文**，四维加权上限只有 30% → 标题抄袭永远拦不住 | 正文 <30 字时**退回标题单维判定** |
| 9 | 小红书**图片有防盗链**（直接引用 403） | 走 `GET /api/img?url=` 本地代理（带 Referer）|

## 九、文档维护规则（重要）

**每次完成一项机制，必须同时更新这三个文件（不能只更一个）：**

| 文件 | 更新什么 |
|---|---|
| **`00_机制台账_实时更新.md`**（本文件）| 机制状态 ✅/⬜、进度百分比、变更日志 |

| **`06_系统机制说明书.md`** | 末尾「最新落地状态」表 |

进度清晰才不会遗漏 —— 两者都要，缺一不可。

**另外**：`xhs-ops-platform` 技能里也有一份进度快照 + 关键技术突破 + 踩过的坑，一并同步。
