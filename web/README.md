# 绮点 AI 小红书运营平台 Demo

面向化妆培训机构、美妆、穿搭与时尚行业的 AI 小红书运营工作台前端 Demo。

当前版本用于展示产品界面和关键交互，不包含真实账号授权、真实密钥、自动发布或线上数据。

## 已展示功能

- 今日运营：首页概览、内容热度、发布排期、原创度状态
- 内容工坊：按照连续七天大纲批量生成内容，支持图片数量与内容类型配置
- 排期发布：查看发布队列、切换自动发布状态、预览待发内容
- 素材灵感：按妆容、穿搭、课堂、案例筛选并多选素材
- 数据洞察：浏览、涨粉、咨询和到店数据，以及每日复盘优化建议
- 运营大纲：七天内容进度、上下文承接关系和转化路径
- 文案库：历史内容检索、语义查重和 60% 相似度硬门禁
- 系统设置：DeepSeek、QweAPI img2.5、小红书 MCP 与本地环境状态展示

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

质量检查：

```bash
npm run lint
npm run build
```

## 安全说明

- 不要把 DeepSeek、QweAPI 或任何第三方密钥提交到仓库。

- 真实发布前必须经过账号授权、内容合规和人工确认。
